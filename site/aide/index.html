Guide d'installation

Installer Claudio pas à pas

Deux étapes méritent un peu d'accompagnement : la clé API Anthropic et la permission Accessibilité. Rien de compliqué : comptez cinq minutes, une seule fois.

1

Installer l'application

  1. Téléchargez Claudio (fichier zip).
  2. Double-cliquez le zip pour le décompresser, puis glissez Claudio.app dans votre dossier Applications.
  3. Double-cliquez sur Claudio : la moustache apparaît dans la barre de menus, en haut à droite de l'écran.

Aucune alerte de sécurité : l'app est signée et notarisée par Apple. Si macOS affichait malgré tout un avertissement, c'est que le téléchargement vient d'une autre source : repassez par ce site ou par GitHub.

2

Créer votre clé API Anthropic

La clé API, c'est ce qui relie Claudio au moteur Claude d'Anthropic. Elle vous appartient : vous payez uniquement ce que vous consommez, sans abonnement, et une action courte revient à moins d'un centime. Pas besoin d'un abonnement Claude : la console API est un service distinct, avec son propre compte gratuit.

  1. Créez un compte sur console.anthropic.com (e-mail ou compte Google). C'est la console « développeur » d'Anthropic. Ne vous laissez pas impressionner : vous n'y ferez que trois clics.
  2. Ajoutez du crédit : menu Settings → Billing, puis achetez des crédits (5 $ minimum, de quoi tenir des mois d'usage quotidien).
  3. Créez la clé : Settings → API keys → Create key. Donnez-lui un nom (« Claudio ») et copiez la clé qui commence par sk-ant-… : elle ne s'affiche qu'une seule fois.
  4. Dans Claudio : cliquez la moustache dans la barre de menus → Réglages… → onglet Clé API → collez la clé → Enregistrer.

Où va la clé ? Dans le Trousseau macOS, chiffrée par le système. Claudio n'a aucun serveur : la clé et vos textes ne transitent que de votre Mac à l'API Anthropic, en HTTPS. Le code est open source : chacun peut le vérifier.

3

Autoriser l'Accessibilité

C'est le mécanisme officiel de macOS qui permet à Claudio de lire le texte que vous sélectionnez dans une autre app, puis d'y coller le résultat. Sans cette permission, rien ne peut fonctionner.

  1. Sélectionnez un mot dans n'importe quelle app et pressez ⌃⌥⌘I (contrôle + option + commande + I) : macOS affiche une demande d'autorisation.
  2. Cliquez Ouvrir les Réglages Système et activez l'interrupteur en face de Claudio dans la liste Accessibilité.
  3. Refaites le raccourci : cette fois, le panneau apparaît.

Si la demande ne s'affiche pas : ouvrez Réglages Système → Confidentialité et sécurité → Accessibilité, cliquez +, choisissez Claudio dans Applications, et activez l'interrupteur. Puis quittez et relancez Claudio (moustache → Quitter Claudio).

✓

C'est prêt, faites le test

Ouvrez Notes, tapez une phrase avec deux ou trois fautes, sélectionnez-la, pressez ⌃⌥⌘I. Le panneau apparaît, la correction s'écrit sous vos yeux, et ⏎ la colle à la place de votre texte. Tous les raccourcis sont listés (et modifiables) dans les Réglages — et si vous n'en retenez qu'un, ⌃⌥⌘K ouvre la palette, qui contient toutes les actions.

En cas de pépin

Le raccourci ne fait rien

Vérifiez que Claudio est bien activé dans Réglages Système → Confidentialité et sécurité → Accessibilité. Après un changement de permission, quittez et relancez Claudio (moustache → Quitter Claudio, puis rouvrez l'app). Vérifiez aussi qu'une autre app n'utilise pas déjà le même raccourci.

« Erreur 401 » dans le panneau

La clé API est invalide : mal copiée, tronquée ou révoquée. Recréez une clé sur console.anthropic.com et recollez-la dans Réglages → Clé API.

« Erreur 400 » qui mentionne un espace de travail

Votre clé est « liée à l'identité » : renseignez le champ Espace de travail dans Réglages → Clé API (l'identifiant wrkspc_… se trouve dans la console Anthropic, Settings → Workspaces).

« Credit balance is too low »

Vos crédits API sont épuisés : rechargez dans la console Anthropic, Settings → Billing.

Le panneau dit « Aucune sélection »

Le texte doit être sélectionné (surligné) au moment où vous déclenchez le raccourci. Sélectionnez d'abord, déclenchez ensuite.

Le texte du panneau est trop petit

Réglages → Général → Panneau : quatre tailles, de Petit à Très grand. Le panneau s'élargit avec le texte pour garder des lignes lisibles. Le changement s'applique au panneau suivant.
