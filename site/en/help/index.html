Install guide

Install Claudio step by step

Two steps deserve a little hand-holding: the Anthropic API key and the Accessibility permission. Nothing hard: count five minutes, once.

1

Install the app

  1. Download Claudio (zip file).
  2. Double-click the zip to unpack it, then drag Claudio.app into your Applications folder.
  3. Double-click Claudio: the mustache appears in the menu bar, at the top right of your screen.

No security warning: the app is signed and notarized by Apple. If macOS still shows a warning, the download came from another source: go back through this site or GitHub.

2

Create your Anthropic API key

The API key is what connects Claudio to Anthropic's Claude engine. It's yours: you pay only what you use, with no subscription, and a short action costs less than a cent. No Claude subscription needed: the API console is a separate service with its own free account.

  1. Create an account on console.anthropic.com (email or Google account). It's Anthropic's "developer" console. Don't be intimidated: you'll only make three clicks there.
  2. Add credit: Settings → Billing, then buy credits ($5 minimum, enough for months of daily use).
  3. Create the key: Settings → API keys → Create key. Give it a name ("Claudio") and copy the key starting with sk-ant-…: it's shown only once.
  4. In Claudio: click the mustache in the menu bar → Settings… → API key tab → paste the key → Save.

Where does the key go? Into the macOS Keychain, encrypted by the system. Claudio has no server: your key and your text only travel from your Mac to the Anthropic API, over HTTPS. The code is open source: anyone can check.

3

Grant Accessibility

This is the official macOS mechanism that lets Claudio read the text you select in another app, then paste the result back. Without this permission, nothing can work.

  1. Select a word in any app and press ⌃⌥⌘I (control + option + command + I): macOS shows a permission request.
  2. Click Open System Settings and flip the switch next to Claudio in the Accessibility list.
  3. Press the shortcut again: this time, the panel appears.

If the request doesn't show up: open System Settings → Privacy & Security → Accessibility, click +, pick Claudio in Applications, and flip the switch. Then quit and relaunch Claudio (mustache → Quit Claudio).

✓

You're set, try it

Open Notes, type a sentence with a couple of typos, select it, press ⌃⌥⌘I. The panel appears, the fix writes itself before your eyes, and ⏎ pastes it over your text. All shortcuts are listed (and customizable) in Settings — and if you only remember one, ⌃⌥⌘K opens the palette, which holds every action.

If something goes wrong

The shortcut does nothing

Check that Claudio is enabled in System Settings → Privacy & Security → Accessibility. After changing the permission, quit and relaunch Claudio (mustache → Quit Claudio, then reopen the app). Also check that another app isn't already using the same shortcut.

"Error 401" in the panel

The API key is invalid: mistyped, truncated, or revoked. Create a new key on console.anthropic.com and paste it again in Settings → API key.

"Error 400" mentioning a workspace

Your key is "identity-bound": fill in the Workspace field in Settings → API key (the wrkspc_… ID is in the Anthropic console, Settings → Workspaces).

"Credit balance is too low"

Your API credits are used up: top up in the Anthropic console, Settings → Billing.

The panel says "No selection"

The text must be selected (highlighted) when you trigger the shortcut. Select first, trigger second.

The panel text is too small

Settings → General → Panel: four sizes, from Small to Extra large. The panel widens along with the text so lines stay readable. The change applies to the next panel.
